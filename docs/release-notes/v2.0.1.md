# v2.0.1

Release date: 2026-10-13.

This patch release uses the standard Apache License 2.0 text for automated license detection on pkg.go.dev. It retains the project copyright notice and third-party attributions in NOTICE. The SDK, CLI, dependencies and target behavior are unchanged from v2.0.0.

## License and documentation

Sections 6 and 9 of LICENSE now match the [official Apache License 2.0 text](https://www.apache.org/licenses/LICENSE-2.0.txt). This allows license detection to recognize the full text instead of only the appendix notice. pkg.go.dev requires a recognized redistributable license to display package documentation. See its [license policy](https://pkg.go.dev/license-policy).

Select v2.0.1 to use the updated license text. Published v2.0.0 and v2.0.0-rc.1 module contents remain associated with their original tags and checksums.

## Installation

Run these commands from your application's module:

```sh
go get github.com/zhh2001/p4runtime-go-controller/v2@v2.0.1
go install github.com/zhh2001/p4runtime-go-controller/v2/cmd/p4ctl@v2.0.1
```

Run `go mod tidy` after updating the SDK dependency. No source migration is required from v2.0.0.

CLI archives cover Linux and macOS on amd64 and arm64, plus Windows amd64. They include the updated LICENSE, NOTICE and README, with SPDX SBOMs and a signed checksum file. A CLI installed from source normally reports `dev`; use `go version -m /absolute/path/to/p4ctl` to inspect its module version.

Applications upgrading from v1 should follow the [v2 migration guide](https://github.com/zhh2001/p4runtime-go-controller/blob/v2.0.1/docs/migration-v2.md) and the [v2.0.0 compatibility notes](https://github.com/zhh2001/p4runtime-go-controller/blob/v2.0.0/docs/release-notes/v2.0.0.md). Security maintenance continues on the v2.0 line.
